# Управление категориями продуктов

Проект для демонстрации объектно-ориентированного программирования на Python. Реализованы абстрактный базовый класс `BaseProduct`, классы `Product`, `Category`, а также наследники `Smartphone` и `LawnGrass` с автоматическим подсчетом количества категорий и продуктов, инкапсуляцией цены, валидацией данных, форматированным выводом информации о товарах и логированием создания объектов через миксин.

## Цель проекта

Создать модель товаров и категорий для отработки принципов ООП:
- Инкапсуляция данных (приватный атрибут цены с геттером/сеттером)
- Наследование и расширение базового класса
- Полиморфизм (строковое представление объектов, перегрузка оператора сложения)
- Абстрактные классы и методы (контракт для всех продуктов)
- Примеси (миксины) для логирования создания объектов
- Валидация данных и взаимодействие с пользователем
- Классовые методы и атрибуты для учета созданных объектов
- Защита методов от некорректных типов аргументов

## Основные функции

### Абстрактный класс `BaseProduct`
- Задает интерфейс для всех продуктов: обязательные методы и свойства.
- Определяет абстрактные методы:
  - `price` (property) – геттер цены
  - `price.setter` – сеттер цены
  - `__str__` – строковое представление
  - `__add__` – сложение полных стоимостей продуктов
- Не может быть инстанцирован (вызов `BaseProduct()` вызовет `TypeError`).
- Является родителем для класса `Product`.

### Миксин `MixinLogConsole`
- Примесь, которая добавляет логирование создания объекта.
- В своем `__init__` выводит в консоль `repr(self)`.
- `__repr__` возвращает строку в формате: `"ClassName(name, description, price, quantity)"`.
- Добавляется в цепочку наследования класса `Product` первым, чтобы не нарушить работу `BaseProduct`.
- Позволяет автоматически отслеживать создание любого продукта (включая `Smartphone` и `LawnGrass`) без дублирования кода.

### Класс `Product`
- Наследует `MixinLogConsole` и `BaseProduct`.
- Хранит название, описание, цену и количество товара.
- **Приватный атрибут `__price`** – доступ через свойства `@property` и `@price.setter`.
- **Сеттер цены**:
  - Запрещает установку нулевой или отрицательной цены (выводит сообщение).
  - При попытке понизить цену запрашивает подтверждение у пользователя (ввод 'y').
- **Строковое представление `__str__`** – возвращает строку в формате: `"Название, цена. Остаток: X шт."`.
- **Перегрузка оператора `+`** – вычисляет полную стоимость двух продуктов (цена × количество каждого), если они принадлежат к одному типу (классу), иначе вызывает `TypeError`.
- **Классовый метод `new_product`**:
  - Принимает словарь с данными и опциональный список существующих продуктов.
  - Если продукт с таким именем уже есть в списке, обновляет его количество, описание и цену (только если новая цена выше).
  - Иначе создает новый экземпляр `Product` (при этом срабатывает логирование миксина).
- Ограничивает создание товара с нулевым количеством и прерывает выполнение программы, выводя ошибку `Товар с нулевым количеством не может быть добавлен`
### Класс `Category`
- Хранит название, описание и приватный список продуктов (`__products`).
- **Метод `add_product`** – добавляет объект в категорию **только если он является экземпляром `Product` или его наследником**. В противном случае выбрасывается исключение `TypeError`.
- **Метод `middle_price`** -  подсчитывает средний ценник всех товаров. 
- **Свойство `products`** – возвращает список отформатированных строк с информацией о каждом товаре: `"Название, цена. Остаток: количество шт."`.
- **Строковое представление `__str__`** – возвращает строку в формате: `"Название категории, количество продуктов: общая_сумма_единиц"`.
- **Класс-атрибуты**:
  - `category_count` – общее количество созданных категорий.
  - `product_count` – общее количество продуктов во всех категориях (обновляется при создании категории и добавлении продуктов).

### Классы-наследники `Smartphone` и `LawnGrass`
- **`Smartphone(Product)`** – добавляет атрибуты:
  - `efficiency` (float) – производительность
  - `model` (str) – модель
  - `memory` (int) – объем памяти
  - `color` (str) – цвет
- **`LawnGrass(Product)`** – добавляет атрибуты:
  - `country` (str) – страна-производитель
  - `germination_period` (str) – срок прорастания
  - `color` (str) – цвет
- Оба класса наследуют все методы и свойства `Product` (геттер/сеттер цены, `new_product`, `__str__`, `__add__`) и могут использоваться везде, где ожидается `Product`.
- При создании экземпляров срабатывает логирование миксина (выводится `__repr__` с четырьмя базовыми атрибутами).

## Описание классов

### `BaseProduct` (абстрактный)
- **Абстрактные методы**:
  - `price` (property)
  - `price.setter`
  - `__str__`
  - `__add__`

### `MixinLogConsole`
- **Методы**:
  - `__init__(*args, **kwargs)` – вызывает родительский конструктор, затем выводит `repr(self)`
  - `__repr__(self)` – возвращает строку вида `"ClassName(name, description, price, quantity)"`

### `Product`
- **Атрибуты экземпляра**:
  - `name` (str) – название товара
  - `description` (str) – описание
  - `__price` (float) – цена (приватный)
  - `quantity` (int) – количество на складе
- **Свойства**:
  - `price` – геттер для получения цены
  - `price.setter` – сеттер с проверкой и подтверждением понижения
- **Методы**:
  - `__str__` – строковое представление продукта
  - `__add__(other)` – сложение полных стоимостей двух продуктов одного типа
- **Классовый метод**:
  - `new_product(product_dict, all_products=None)` – создает или обновляет продукт

### `Category`
- **Атрибуты экземпляра**:
  - `name` (str)
  - `description` (str)
  - `__products` (list[Product]) – приватный список продуктов
- **Класс-атрибуты**:
  - `category_count` (int) – счетчик категорий
  - `product_count` (int) – счетчик продуктов
- **Методы**:
  - `add_product(product_obj)` – добавляет продукт в категорию (только объекты `Product` или его наследники)
  - `products` (property) – возвращает отформатированный список товаров
  - `__str__` – возвращает название категории и общее количество единиц товара
  - `middle_price` - возвращает среднюю цену всех товаров

### `Smartphone(Product)`
- **Дополнительные атрибуты**:
  - `efficiency` (float)
  - `model` (str)
  - `memory` (int)
  - `color` (str)

### `LawnGrass(Product)`
- **Дополнительные атрибуты**:
  - `country` (str)
  - `germination_period` (str)
  - `color` (str)

## Примеры использования

```python
from main import BaseProduct, Product, Category, Smartphone, LawnGrass

# Попытка создать абстрактный класс вызовет ошибку
# base = BaseProduct()  # TypeError: Can't instantiate abstract class BaseProduct

# Создание продуктов – при каждом создании в консоль выводится repr
product1 = Product("Samsung Galaxy S23 Ultra", "256GB, Серый цвет, 200MP камера", 180000.0, 5)
product2 = Product("Iphone 15", "512GB, Gray space", 210000.0, 8)

# Наследники тоже логируются (выводят четыре базовых параметра)
smartphone = Smartphone("Xiaomi 12", "512GB", 90000.0, 3, 98.0, "12", 512, "Синий")
grass = LawnGrass("Газон", "Спортивная", 300.0, 15, "Россия", "10 дней", "Зеленый")

# Геттер/сеттер цены работает и в наследниках
smartphone.price = -100  # выведет предупреждение
smartphone.price = 85000.0  # запросит подтверждение, если цена ниже текущей

# Строковое представление
print(str(product1))      # Samsung Galaxy S23 Ultra, 180000.0. Остаток: 5 шт.
print(str(grass))         # Газон, 300.0. Остаток: 15 шт.

# Сложение продуктов одного типа
total_cost = product1 + product2  # 180000*5 + 210000*8 = 2580000.0
# Сложение разных типов вызывает ошибку
# product1 + smartphone  # TypeError

# Категория
category = Category("Смартфоны", "Различные модели", [product1, product2, smartphone])
print(category.name)                # Смартфоны
print(len(category.products))       # 3
print(Category.category_count)      # 1
print(Category.product_count)       # 3

# Добавление продукта через add_product (только Product и наследники)
category.add_product(grass)
print(Category.product_count)       # 4

# Строковое представление категории
print(str(category))                # Смартфоны, количество продуктов: 31 (5+8+3+15)

# Классовый метод new_product
existing = [product1, product2, smartphone, grass]
update_data = {"name": "Xiaomi 12", "description": "Обновлен", "price": 95000.0, "quantity": 2}
updated = Product.new_product(update_data, existing)
print(updated.quantity)  # 3 + 2 = 5
```

## Тестирование

Тесты написаны с использованием `pytest` и находятся в папке `tests/`. Фикстуры определены в `conftest.py`.

**Основные тесты:**
- Инициализация продуктов, категорий и наследников.
- Проверка наследования (`isinstance`, `Smartphone` и `LawnGrass` – наследники `Product`).
- Геттер и сеттер цены (включая проверку у наследников).
- Метод `new_product`: создание, обновление количества и цены.
- Строковые представления `Product.__str__` и `Category.__str__`.
- Перегрузка `__add__` для продуктов одного типа и генерация `TypeError` для разных типов.
- Защита `Category.add_product`: принимает только `Product` и его подклассы, выбрасывает `TypeError` для других объектов.
- Подсчет количества категорий и продуктов через классовые атрибуты.
- Форматирование списка товаров через свойство `products`.
- **Новые тесты**:
  - Невозможность создать экземпляр `BaseProduct` (проверка абстрактности).
  - Вывод `repr` в консоль при создании `Product`, `Smartphone`, `LawnGrass` (проверка миксина).
  - Формат `__repr__` – строка вида `"ClassName(name, description, price, quantity)"`.
  - Корректность работы `Product.new_product` без двойного логирования (при обновлении существующего продукта вывод не происходит).

Запуск всех тестов:
```bash
pytest tests/
```

Примеры новых тестов:
```python
def test_base_product_abstract():
    with pytest.raises(TypeError):
        BaseProduct()

def test_product_creation_logs_repr(capsys):
    p = Product("Телефон", "Описание", 15000, 3)
    captured = capsys.readouterr()
    assert captured.out == "Product(Телефон, Описание, 15000, 3)\n"
```
