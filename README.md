# Управление категориями продуктов

Проект для демонстрации объектно-ориентированного программирования на Python. Реализованы классы `Product` и `Category` с автоматическим подсчетом количества категорий и продуктов, инкапсуляцией цены, возможностью обновления продуктов и форматированным выводом списка товаров.

## Цель проекта

Создать модель товаров и категорий для отработки базовых принципов ООП:
- Инкапсуляция данных (приватный атрибут цены с геттером/сеттером)
- Работа с классовыми методами и атрибутами
- Валидация данных и взаимодействие с пользователем
- Подсчет общего количества категорий и продуктов
- Легкое расширение функциональности

## Основные функции

### Класс `Product`
- Хранит название, описание, цену и количество товара.
- **Приватный атрибут `__price`** – доступ через свойства `@property` и `@price.setter`.
- **Сеттер цены**:
  - Запрещает установку нулевой или отрицательной цены (выводит сообщение).
  - При попытке понизить цену запрашивает подтверждение у пользователя (ввод 'y').
- **Классовый метод `new_product`**:
  - Принимает словарь с данными и опциональный список существующих продуктов.
  - Если продукт с таким именем уже есть в списке, обновляет его количество, описание и цену (только если новая цена выше).
  - Иначе создает новый экземпляр `Product`.
- Поддерживает подсчет созданных объектов (необязательно).

### Класс `Category`
- Хранит название, описание и приватный список продуктов (`__products`).
- **Метод `add_product`** – добавляет объект `Product` в категорию и увеличивает общий счетчик продуктов.
- **Свойство `products`** – возвращает список отформатированных строк с информацией о каждом товаре: `"Название, цена. Остаток: количество шт.\n"`.
- **Класс-атрибуты**:
  - `category_count` – общее количество созданных категорий.
  - `product_count` – общее количество продуктов во всех категориях (обновляется при создании категории и добавлении продуктов).

## Описание классов

### `Product`
- **Атрибуты экземпляра**:
  - `name` (str) – название товара
  - `description` (str) – описание
  - `__price` (float) – цена (приватный)
  - `quantity` (int) – количество на складе
- **Свойства**:
  - `price` – геттер для получения цены
  - `price.setter` – сеттер с проверкой и подтверждением понижения
- **Классовый метод**:
  - `new_product(product_dict, all_products=None)` – создает или обновляет продукт

### `Category`
- **Атрибуты экземпляра**:
  - `name` (str)
  - `description` (str)
  - `__products` (list[Product]) – приватный список продуктов
- **Класс-атрибуты**:
  - `category_count` (int) – счетчик категорий
  - `product_count` (int) – счетчик продуктов
- **Методы**:
  - `add_product(product_obj)` – добавляет продукт в категорию
  - `products` (property) – возвращает отформатированный список товаров

## Примеры использования

```python
from main import Product, Category

# Создание продуктов
product1 = Product("Samsung Galaxy S23 Ultra", "256GB, Серый цвет, 200MP камера", 180000.0, 5)
product2 = Product("Iphone 15", "512GB, Gray space", 210000.0, 8)

# Попытка установить некорректную цену
product1.price = -100  # выведет: "Цена не должна быть нулевая или отрицательная"
product1.price = 150000.0  # запросит подтверждение, если цена ниже текущей

# Создание категории
category = Category("Смартфоны",
                    "Смартфоны как средство коммуникации",
                    [product1, product2])

print(category.name)               # Смартфоны
print(len(category.products))      # 2
print(Category.category_count)     # 1
print(Category.product_count)      # 2

# Добавление нового продукта в категорию
product3 = Product("Xiaomi Redmi Note 11", "1024GB, Синий", 31000.0, 14)
category.add_product(product3)
print(Category.product_count)      # 3

# Вывод всех товаров категории в отформатированном виде
for product_str in category.products:
    print(product_str, end='')
# Samsung Galaxy S23 Ultra, 180000.0. Остаток: 5 шт.
# Iphone 15, 210000.0. Остаток: 8 шт.
# Xiaomi Redmi Note 11, 31000.0. Остаток: 14 шт.

# Использование классового метода new_product
existing_products = [product1, product2, product3]
new_data = {
    "name": "Samsung Galaxy S23 Ultra",
    "description": "Обновленная версия",
    "price": 190000.0,
    "quantity": 2
}
updated = Product.new_product(new_data, existing_products)
print(updated.quantity)  # 5 + 2 = 7
print(updated.price)     # 190000.0 (выше старой)
```

## Тестирование

Тесты написаны с использованием `pytest` и находятся в папке `tests/`. Фикстуры (например, готовые объекты продуктов) определены в `conftest.py`.

**Основные тесты:**
- Инициализация продуктов и категорий.
- Проверка работы геттера и сеттера цены (включая подтверждение понижения).
- Корректность метода `new_product` (создание, обновление, выбор максимальной цены).
- Подсчет количества категорий и продуктов.
- Форматирование списка товаров через свойство `products`.
- Добавление продукта в категорию.

Запуск всех тестов:
```bash
pytest tests/
```

Пример одного из тестов:
```python
def test_product_price_setter_lower_with_confirmation(product_samsung, monkeypatch):
    monkeypatch.setattr('builtins.input', lambda _: 'y')
    old_price = product_samsung.price
    product_samsung.price = old_price - 10000
    assert product_samsung.price == old_price - 10000
```
